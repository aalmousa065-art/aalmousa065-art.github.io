# LAST EXIT: City Stories

A stylized 3D crime-story alpha with 19 quests, choices, driving and free roam.

Play in the browser or download the Windows edition. Phones use landscape touch controls. The cover illustration is concept art; gameplay screenshots show the actual graphics.

The editable Godot 4.7.2 project is in game-source. Open project.godot in Godot. Mobile controls have automated input checks; physical phone and controller checks remain necessary.

The campaign is not yet six to nine real days long. Console distribution requires a separate approved console port.

Website: pnpm install, pnpm dev, pnpm build. Node 22 is recommended on Windows; Node 24 encountered a native shutdown issue in this environment.

Godot license and copyright notices are included in game-source and the Windows download.
